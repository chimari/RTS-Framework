# Step02 – Statistical Characterization

## Purpose

Step02 performs deterministic statistical characterization of image
datasets prepared by Step01.

It organizes image frames into validated dataset groups, computes
reproducible statistical information, and prepares documented outputs
required by subsequent pipeline stages.

Step02 is intentionally detector-independent, never modifies detector
image data, and performs no detector calibration or scientific
interpretation.

---

## Position in the Pipeline

```
Raw Images
      │
      ▼
Step01  Dataset Preparation
      │
      ▼
Step02  Statistical Characterization
      │
      ▼
Step03  RTS Candidate Detection
```

Step02 consumes the normalized dataset manifest produced by Step01 and
generates validated dataset groups together with statistical summaries.
These outputs become the documented interface to downstream processing.

---

## Design principles

Step02 follows five principles.

1. Preserve deterministic processing.
2. Never modify detector image data.
3. Load image data only when required.
4. Produce reproducible statistical outputs.
5. Separate detector-independent processing from detector-specific behavior.

These principles define the architectural boundary of Step02 and guide
future extensions.

---

## Dataset Grouping

Frames are grouped into immutable DatasetGroup objects according to the
normalized manifest produced by Step01.

Grouping preserves acquisition order and never changes frame metadata.

Every frame belongs to exactly one dataset group.

---

## Lazy Image Loading

Image arrays are not stored inside DatasetGroup.

Images are loaded only when requested through the public image I/O
interface.

This minimizes memory usage and allows processing of large detector
datasets.

---

## Statistical Characterization

Step02 computes deterministic statistical information for each dataset.

The resulting statistics are exported as CSV and JSON artifacts that
serve as documented interfaces for downstream processing.

---

## Inputs

Required inputs

- normalized_manifest.csv produced by Step01
- detector image files referenced by the manifest
    - FITS
    - RAW (supported formats)

---

## Outputs

Step02 produces both Python objects and persistent artifacts.

| Output | Description |
|---------|-------------|
| DatasetGroup | Immutable grouped dataset object |
| Statistics CSV | Per-frame statistical information |
| Summary JSON | Dataset summary and metadata |

Additional analysis products may be generated by optional processing
modules (for example, Read Noise Analysis).

---

## Processing Flow

```
normalized_manifest.csv
        │
        ▼
Read manifest
        │
        ▼
Group frames
        │
        ▼
Validate datasets
        │
        ▼
Lazy image loading
        │
        ▼
Compute statistics
        │
        ▼
Export CSV
        │
        ▼
Export Summary JSON
        │
        ▼
Step03
```

Every processing step is deterministic and reproducible.

## Command Line Interface

```bash
python -m steps.step02_prepare_frame_groups MANIFEST
```

CSV and JSON export:

```bash
python -m steps.step02_prepare_frame_groups MANIFEST     --statistics-dir output/statistics     --summary-dir output/summaries
```

Other options:

- `--frame-root DIRECTORY`
- `--quiet`
- `--version`
- `--help`

Exit status is `0` on success and `2` for command-line or Step 02 errors.

### Example

```bash
python -m steps.step02_prepare_frame_groups \
    normalized_manifest.csv \
    --frame-root ./data
```

Additional optional analysis modules may be enabled through command-line
options.
