# Step03 Validation

## Overview

Step03 validates the identification of RTS candidate pixels from the
statistics generated by Step02.

This step determines which pixels should be examined further during RTS
state estimation.

---

## Purpose

The objective of Step03 is to generate a reproducible list of RTS
candidate pixels using well-defined selection criteria.

Validation ensures that candidate selection remains stable unless the
selection algorithm is intentionally modified.

---

## Scope

This validation covers:

- candidate selection;
- threshold application;
- ranking;
- output formatting.

State estimation and image correction are outside the scope of this
step.

---

## Inputs

Step03 requires:

    statistics.csv

---

## Expected Output

The primary output is

    candidate_list.csv

This file becomes the input for Step04.

---

## Reference Artifact

The expected candidate list will be stored as

    fixtures/expected_candidate_list.csv

---

## Validation Procedure

The validation procedure is:

      statistics.csv
             │
             ▼
          Step03
             │
             ▼
   candidate_list.csv
             │
             ▼
 compare_candidate_list.py
             │
             ▼
        PASS / FAIL

The comparison verifies:

- identical candidate count;
- identical pixel coordinates;
- identical ordering;
- identical associated quantities.

---

## Acceptance Criteria

Validation succeeds only if the generated candidate list satisfies the
defined comparison criteria.

Intentional algorithmic improvements require review and updated
reference artifacts.
