# Step05 Validation

## Overview

Step05 validates the correction of detector images using the RTS
dictionary generated by Step04.

This step produces corrected images suitable for subsequent scientific
analysis.

---

## Purpose

The objective of Step05 is to ensure that RTS correction is applied
consistently and reproducibly to every affected pixel.

Validation verifies that the correction algorithm produces the expected
output without modifying unaffected image content.

---

## Scope

This validation covers:

- dictionary loading;
- RTS correction;
- corrected image generation;
- metadata preservation;
- output formatting.

Scientific performance evaluation is outside the scope of this step.

---

## Inputs

Step05 requires:

    rts_dictionary.csv

and

    detector image

to be corrected.

---

## Expected Output

The primary output is

    corrected_image.fits

Additional diagnostic products may also be generated.

---

## Reference Artifact

The expected corrected image will be stored as

    fixtures/expected_corrected_image.fits

Reference images should be generated from a controlled validation
dataset.

---

## Validation Procedure

The validation procedure is:

      detector image
             +
      RTS dictionary
             │
             ▼
          Step05
             │
             ▼
   corrected_image.fits
             │
             ▼
 compare_corrected_image.py
             │
             ▼
        PASS / FAIL

The comparison verifies:

- identical image dimensions;
- identical metadata;
- expected corrected pixel values;
- preservation of unaffected pixels;
- statistical consistency.

---

## Acceptance Criteria

Validation succeeds when the corrected image satisfies the defined
comparison criteria.

Image differences shall remain within the documented numerical
tolerances.

Unexpected changes affecting unaffected regions are treated as
regressions.

---

## Current Status

---

## Future Scientific Validation

Future validation may evaluate correction performance using synthetic
RTS datasets, laboratory measurements, and astronomical observations.

Performance metrics may include:

- residual RTS fraction;
- image noise reduction;
- preservation of photometric accuracy;
- preservation of fixed-pattern characteristics.
